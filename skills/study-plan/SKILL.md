# Study plan

Read the student's available topics, unresolved weaknesses and existing calendar commitments. Plan backwards from the stated assessment date. If study time is unspecified, choose a modest clearly stated assumption and make a plan the student can adjust.

Assign each session a concrete learning result and an activity that proves it, such as solving three mixed problems without hints. Alternate focused repair with spaced retrieval and mixed practice. Leave spare capacity for missed sessions and harder topics. Keep blocks short enough for the stated availability. Explain priorities using the exam scope and observed weaknesses.

Present dates, durations and outcomes in a compact schedule. Before creating calendar entries, ensure that scheduling is part of the user's request. Use actual tool results to avoid conflicts where calendar inspection is available. Respect timezone and distinguish all-day deadlines from timed study blocks. Report only entries that were successfully saved.
