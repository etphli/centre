# Essay writing

Start from the assignment question, required length and available rubric. Identify the claim the essay must defend and the evidence available. Separate the author's position, a source's position and an inference. Use supplied sources precisely; mark missing evidence rather than inventing quotations or citations.

Build paragraphs around claims that advance the argument. Connect each piece of evidence to the claim and address the strongest relevant counterargument. Keep introductions proportionate and make the conclusion answer the question using the analysis already established.

For feedback, prioritize argument and evidence before line edits. Explain a few important revisions with examples, preserving the student's intended voice. When the user requests an outline, provide an outline. When they request revision, return the revised text. Apply unslop for plain prose. Save a Centre note only when the task asks for saved work and the relevant tool succeeds.
